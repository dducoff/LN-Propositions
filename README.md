# LN-Propositions - a LeanNotes repo

- This project contains propositional logic proofs.
- The [LeanNotes Table of Contents for propositional logic](https://leannotes.wiki/Proofs/Propositional+Logic/Table+of+Contents) 
    contains links to several derivation categories.  
- Each derivation category has: 
  - A link to its own directory in this repo.
  - An overview of what the derivation rules mean.
  - A list of the tactics used in the proofs stored in this repo.
  - Links to video annotations of the proofs.
  - Links to learning resources that use the derivation rules.
  - Author credits and a (very generous) copyright notice. 

- Note: This project uses the Lean 4 toolchain version: **v4.33.0**
