- This repo contains propositional logic proofs written in Lean version **4.33.0**.
- The [LeanNotes wiki](https://leannotes.wiki/LeanNotes+Home) contains pages that annotate these proofs.
- Refer to the [LeanNotes Table of Contents for Propositional Logic](https://leannotes.wiki/Proofs/Propositional+Logic/Table+of+Contents) for a listing of the proof annotations.
- Each annotation has a link to Lean code. For instance, the [Negation annotation page](https://leannotes.wiki/Proofs/Propositional+Logic/Negation) contains a link to its corresponding [Lean proofs](https://github.com/dducoff/LN-Propositions/blob/main/Negation/Negation.lean).

- Additionally, each annotation includes:
  - An overview of what the derivation rules mean.
  - A list of the tactics used in the proofs.
  - Links to video annotations of the proofs.
  - Links to learning resources that use the derivation rules.
  - Author credits and a very generous copyright notice.
